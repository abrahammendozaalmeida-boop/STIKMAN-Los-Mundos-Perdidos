# Banco de Texturas Vectoriales

Biblioteca de recursos vectoriales para STIKMAN - Los Mundos Perdidos.

Compatible con Godot 3.5.3 mediante archivos SVG.

Contenido inicial:
- fondos y cielos
- selva
- tierra y piedra
- agua
- estrellas y espacio
- tecnología/IA
- Júpiter
- efectos visuales

Los archivos de esta carpeta son recursos originales de este proyecto y sirven como base/prototipos. Se pueden ampliar con paquetes externos cuya licencia permita su uso.
