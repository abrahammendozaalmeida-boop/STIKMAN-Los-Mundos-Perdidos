# STIKMAN - LOS MUNDOS PERDIDOS

Proyecto desarrollado en Godot 3.5.3.

## Prologo
Stikman despierta en una selva desconocida. No hay nadie alrededor y no sabe como llego hasta ahi.

## Controles
- A / D o flechas: mover
- ESPACIO: saltar

## Mundos
1. Mundo Normal
2. Fantasia / Universo
3. La IA apoderandose de todo
4. Jupiter
5. Por definir
